# Roadmap

## v0.1 — bounded witness

- dependency-free `.ora` ZIP and XML checks;
- typed JSON findings with stable ordering;
- baseline layer references, required previews, and selected loss-risk signals;
- synthetic tests and explicit limitations.

## Later, only with evidence

- support for `.ora` files larger than the current streaming assumptions;
- optional PNG metadata checks if a maintainer or producer needs them;
- a documented extension profile, only when an application consortium supplies
  a stable contract.

## Explicitly out of scope

Rendering comparison, application emulation, automatic repair, proprietary
extension inference, and archival certification require external consumer
evidence and are not implied by this project.
