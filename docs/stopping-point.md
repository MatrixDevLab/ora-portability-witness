# Stopping point

Stop after the bounded witness is shipped and its local checks are green.

Do not add a renderer, application matrix, repair mode, or extension catalog
just to make the project larger. Continue only if an external producer or
maintainer supplies a concrete archive class that the local evidence boundary
can address without pretending to predict application-specific rendering.

The falsifier is simple: if a maintained ORA validator already emits the same
typed, location-rich baseline/loss-risk report, or if users need rendered
cross-application comparison rather than archive evidence, this repository
should stop rather than duplicate that work.
